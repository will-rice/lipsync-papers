# Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement

###### Abstract

In this paper, we are interested in unsupervised (unknown noise)
audio-visual speech enhancement based on variational autoencoders
(VAEs), where the probability distribution of clean speech spectra is
simulated using an encoder-decoder architecture. The trained generative
model (decoder) is then combined with a noise model at test time to
estimate the clean speech. In the speech enhancement phase (test time),
the initialization of the latent variables, which describe the
generative process of clean speech via decoder, is crucial, as the
overall inference problem is non-convex. This is usually done by using
the output of the trained encoder where the noisy audio and clean visual
data are given as input. Current audio-visual VAE models do not provide
an effective initialization because the two modalities are tightly
coupled (concatenated) in the associated architectures. To overcome this
issue, inspired by mixture models, we introduce the mixture of inference
networks variational autoencoder (MIN-VAE). Two encoder networks input,
respectively, audio and visual data, and the posterior of the latent
variables is modeled as a mixture of two Gaussian distributions output
from each encoder network. The mixture variable is also latent, and
therefore the inference of learning the optimal balance between the
audio and visual inference networks is unsupervised as well. By training
a shared decoder, the overall network learns to adaptively fuse the two
modalities. Moreover, at test time, the visual encoder, which takes
(clean) visual data, is used for initialization. A variational inference
approach is derived to train the proposed generative model. Thanks to
the novel inference procedure and the robust initialization, the
proposed MIN-VAE exhibits superior performance on speech enhancement
than using the standard audio-only as well as audio-visual counterparts.

###### Index Terms: 

Audio-visual speech enhancement, generative models, variational
auto-encoder, mixture model.

## I Introduction

Speech enhancement, or removing background noise from noisy
speech \[[1](#bib.bib1), [2](#bib.bib2)\], is a classic yet very
important problem in signal processing and machine learning. Traditional
solutions to this problem are based on spectral
subtraction \[[3](#bib.bib3)\] and Wiener filtering \[[4](#bib.bib4)\],
targeting noise and/or speech PSD (PSD) estimation in the STFT (STFT)
domain. The recent impressive performance of DNNs (DNNs) in computer
vision and machine learning has paved the way to revisit the speech
enhancement problem. DNNs have been widely utilized in this regard,
where a neural network is trained to map a noisy speech spectrogram to
its clean version, or to a TF (TF) mask \[[5](#bib.bib5),
[6](#bib.bib6), [7](#bib.bib7)\]. This is usually done in a supervised
way, using a huge dataset of noise and clean speech signals for
training. As such, the performance of a supervised speech enhancement
technique often degrades when dealing with an unknown type of noise.

Unsupervised techniques provide another procedure for speech enhancement
that does not use noise signals for training. A popular unsupervised
method is based on NMF (NMF)  \[[8](#bib.bib8), [9](#bib.bib9),
[10](#bib.bib10)\] for modeling the PSD of speech
signals \[[11](#bib.bib11)\], which decomposes PSD as a product of two
non-negative low-rank matrices (a dictionary of basis spectra and the
corresponding activations). An NMF-based speech enhancement method
consists of first learning a set of basis spectra for clean speech
spectrograms at training phase, prior to speech enhancement
\[[12](#bib.bib12), [13](#bib.bib13), [9](#bib.bib9)\]. Then, by
decomposing the noisy spectrogram as the sum of clean speech and noise
spectrograms, the corresponding clean speech activations as well as the
NMF parameters of noise are estimated. While being computationally
efficient, this modeling and enhancement framework cannot properly
explain complicated structure of speech spectrogram due to the limited
representational power dictated by the two low-rank matrices. A deep
autoencoder (DAE) has been employed in \[[14](#bib.bib14)\] to model
clean speech and noise spectrograms. A DAE is pre-trained for clean
speech spectrograms, while an extra DAE for noise spectrogram is trained
at the enhancement stage using the noisy spectrogram. The corresponding
inference problem is under-determined, and the authors proposed to
constrain the unknown speech using a pre-trained NMF model. As such,
this DAE-based method might encounter the same shortcomings as those of
the NMF-based speech enhancement \[[15](#bib.bib15)\].

Deep latent variable models offer a more sophisticated and efficient
modeling framework than NMF and DAE, gaining much interest over the past
few years \[[15](#bib.bib15), [16](#bib.bib16), [17](#bib.bib17),
[18](#bib.bib18), [19](#bib.bib19), [20](#bib.bib20),
[21](#bib.bib21)\]. The first and main step is to train a generative
model for clean speech spectrogram using a VAE (VAE) \[[22](#bib.bib22),
[23](#bib.bib23)\]. VAE provides an efficient way to estimate the
parameters of a non-linear generative model, also called the decoder.
This is done by approximating the intractable posterior distribution of
the latent variables using a Gaussian distribution parametrized by a
neural network, called the inference (encoder) network. The encoder and
decoder are jointly trained to maximize a variational lower bound on the
marginal data log-likelihood. At test time, the trained generative model
is combined with a noise model, e.g. NMF. The unknown noise parameters
and clean speech are then estimated from the observed noisy speech.
Being independent of the noise type at training, these methods show
better generalization than the supervised approaches \[[15](#bib.bib15),
[16](#bib.bib16)\].

Motivated by the fact that the visual information, when associated with
audio information, often helps improve the performance in various
tasks \[[24](#bib.bib24), [25](#bib.bib25), [26](#bib.bib26)\], and in
particular the quality of speech enhancement \[[27](#bib.bib27),
[28](#bib.bib28), [29](#bib.bib29)\], an audio-visual latent variable
generative model has recently been proposed in \[[30](#bib.bib30)\].
Within this model, the visual features corresponding to the lips region
of the speaker are also fed to the encoder and decoder networks of the
VAE. The effectiveness and superior performance of the audio-visual VAE
(AV-VAE) compared to the audio-only VAE (A-VAE), as well as the
supervised deep learning based method of \[[29](#bib.bib29)\] has been
experimentally verified in \[[30](#bib.bib30)\]. To deal with noisy
visual data at test time, e.g. non-frontal or occluded lips images, a
robust method has been proposed in \[[31](#bib.bib31)\], which was later
improved and extended in \[[32](#bib.bib32)\]. In the proposed approach,
a mixture of trained A-VAE and AV-VAE is used as the clean speech model
during speech enhancement. Because of that, the deteriorating effects
associated with missing/noisy visual information are avoided as the
algorithm switches from AV-VAE to A-VAE in these
cases \[[31](#bib.bib31)\]. Besides AV-VAE, a video-only VAE (V-VAE) has
also been introduced in \[[30](#bib.bib30)\], where the posterior
parameters of the latent variables, that is, the encoder parameters, are
trained using only visual information. As such, the latent variables
governing the generative process of clean speech spectrogram are
inferred from visual data only. V-VAE has been shown to yield much
better speech enhancement performance than A-VAE when the (acoustic)
noise level is high \[[30](#bib.bib30)\].

In the speech enhancement phase, because of the non-linear generative
model, the posterior of the latent variables does not admit a
closed-form expression. Two approaches are often used to get around this
problem. The first solution is based on the Markov Chain Monte Carlo
(MCMC) method \[[33](#bib.bib33)\], in which a sampling technique, e.g.
the Metropolis-Hastings algorithm \[[33](#bib.bib33)\], is used to
sample from the posterior \[[15](#bib.bib15), [16](#bib.bib16)\]. The
obtained samples are then used to approximate the expectations using a
Monte-Carlo average. The second approach makes use of optimization
techniques to find the maximum a posteriori estimation of the latent
variables \[[20](#bib.bib20)\]. In either case, the initialization plays
an important role, as the associated problems are highly non-convex. In
practice, the trained encoder is used to initialize the latent variables
by giving the noisy speech spectrogram as the input and taking the
posterior mean at the output. This can partly explain why V-VAE performs
better than A-AVE at high noise levels. In fact, the latent variable
initialization in V-VAE is based on visual features, whereas in A-VAE,
it is based on the noisy speech. As a result, V-VAE provides a better
initialization, because it uses noise-free data (visual
features) \[[30](#bib.bib30)\].

The original contribution of this paper is to optimally exploit the
complementarity of A-VAE and V-VAE, without systematic recourse to
simultaneously using audio and visual features, i.e. via simple
concatenation (tight fusion) as done in AV-VAE. Indeed, we aim to bridge
the performance gap between A-VAE and V-VAE by designing a mixture of
audio and visual inference (encoder) networks, called mixture of
inference networks VAE (MIN-VAE). The inputs to audio and visual
encoders are speech spectrogram frames and the corresponding visual
features, respectively, thus training MIN-VAE to select the best
combination of the the audio and visual information. A variational
inference approach is proposed to train the mixture of the two encoders
jointly with a shared decoder (generative) network. This way, the
decoder reconstructs the input audio data using the optimal combination
of the audio and visual latent samples. At test time, the latent
variables are initialized using the visual encoder, thus providing a
robust initialization. Our experiments show that MIN-VAE yields much
better performance than previous methods, i.e. A-VAE, V-VAE, and AV-VAE.

It should be noted that there are some fundamental differences between
our proposed MIN-VAE and the mixture model introduced in
\[[31](#bib.bib31)\]. While the purpose of our work is to combine an
A-VAE with a V-VAE to take advantage of the both in terms of robust
initialization and an improved generative model, the work in
\[[31](#bib.bib31)\] addresses robust audio-visual speech enhancement.
We achieve our goal by proposing a VAE architecture with a single
decoder but a mixture of audio- and visual-based encoders. A new
inference method is also derived to train the proposed VAE. In
\[[31](#bib.bib31)\], the robustness is achieved by considering a
mixture of an A-VAE’s decoder and an AV-VAE’s decoder at test phase.
Both the decoders have been trained separately (using standard A-VAE and
AV-VAE), and no particular VAE architecture is trained. In contrast to
our present work, the architecture proposed in \[[31](#bib.bib31)\] does
not provide robustness to latent initialization as it uses a VAE
architecture where the audio and visual modalities are tightly fused.

## II VAE-based Speech Modeling

In this section, audio-only, visual-only and audio-visual clean speech
modeling based on VAE is reviewed. Roughly speaking, this consists in
defining a latent variable generative model for each time frame of clean
speech spectrogram. A parametric Gaussian distribution is used to define
the conditional distribution of a spectrogram time frame given its
associated latent variable (and, depending on the choice, the visual
feature vector). The parameters of the distribution are modeled by DNNs.
Assuming a standard Gaussian prior distribution for the latent
variables, the model (DNN) parameters are then learned from a collection
of clean training data using variational inference. To do so, the
posterior distribution of the latent variables is approximated by a
Gaussian distribution parametrized by a DNN, called the encoder network.
In what follows, three VAE-based modeling frameworks are reviewed.

### II-A Audio-only VAE

Let $`{\bf s}_{n}\in\mathbb{C}^{F}`$ denote the vector of speech STFT
coefficients at time frame $`n`$, for $`n\in\{0,...,N-1\}`$, which is
assumed to be generated according to the following latent variable
model \[[15](#bib.bib15), [16](#bib.bib16)\]:

|     |                                 |                                                          |                                                                                                                            |     |
| --- | ------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle{\bf s}\_{n}     | \mathbf{z}\_{n}`$                                        | $`\displaystyle\sim\mathcal{N}_{c}\Big(\boldsymbol{0},\text{diag}\Big(\boldsymbol{\sigma}_{s}(\mathbf{z}_{n})\Big)\Big),`$ |     | (1) |
|     | $`\displaystyle\mathbf{z}_{n}`$ | $`\displaystyle\sim\mathcal{N}(\mathbf{0},\mathbf{I}),`$ |                                                                                                                            | (2) |

where $`\mathbf{z}_{n}\in\mathbb{R}^{L}`$, with $`L\ll F`$, is a latent
random variable,
$`\mathcal{N}_{c}(\mathbf{0},{\mbox{\boldmath$\Sigma$}})`$ denotes a
zero-mean complex proper Gaussian distribution with covariance matrix
$`\Sigma`$, and $`\mathcal{N}(\mathbf{0},\mathbf{I})`$ stands for a
zero-mean Gaussian distribution with an identity covariance matrix.
Moreover,
$`\boldsymbol{\sigma}_{s}(.):\mathbb{R}^{L}\mapsto\mathbb{R}_{+}^{F}`$
is modeled with a neural network parameterized by
$`\boldsymbol{\theta}`$, which is called the decoder.

In order to estimate the set of parameters, $`\boldsymbol{\theta}`$, the
VAE formalism proposes to approximate the intractable posterior
distribution $`p(\mathbf{z}_{n}|\mathbf{s}_{n})`$ by a variational
distribution parametrized by a neural network, called the inference
(encoder) network \[[23](#bib.bib23)\]. This variational distribution
writes:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
q(\mathbf{z}_{n}|\mathbf{s}_{n};\boldsymbol{\phi}_{a})=\mathcal{N}\Big(\boldsymbol{\mu}_{z}^{a}({\bf s}_{n}),\text{diag}\Big(\boldsymbol{\sigma}_{z}^{a}(\mathbf{s}_{n})\Big)\Big),
``` |  | (3) |

where,
$`\boldsymbol{\mu}_{z}^{a}(.):\mathbb{R}_{+}^{F}\mapsto\mathbb{R}^{L}`$
and
$`\boldsymbol{\sigma}_{z}^{a}(.):\mathbb{R}_{+}^{F}\mapsto\mathbb{R}_{+}^{L}`$
are neural networks, with parameters denoted $`\boldsymbol{\phi}_{a}`$,
taking
$`\tilde{\mathbf{s}}_{n}\triangleq(|s_{0n}|^{2}\dots|s_{F-1\>n}|^{2})^{\top}`$
as input. Given a sequence of STFT speech time frames
$`{\bf s}=\left\{{\bf s}_{n}\right\}_{n=0}^{N_{tr}-1}`$ as training
data, with $`{\bf z}=\left\{{\bf z}_{n}\right\}_{n=0}^{N_{tr}-1}`$ being
the associated latent variables, the parameters
$`\left\{\boldsymbol{\theta},\boldsymbol{\phi}_{a}\right\}`$ are then
estimated by maximizing a lower bound on the data log-likelihood
$`\log p({\bf s};\boldsymbol{\theta})`$. Note that,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\log p({\bf s};\boldsymbol{\theta})`$ | $`\displaystyle=\log\int p({\bf s}|{\bf z};\boldsymbol{\theta})p({\bf z})d{\bf z}`$ |  |  |
|  |  | $`\displaystyle\geq\mathbb{E}_{q({\bf z}|\mathbf{s};\boldsymbol{\phi}_{a})}\Big[\log\frac{p({\bf s}|{\bf z};\boldsymbol{\theta})p({\bf z})}{q({\bf z}|\mathbf{s};\boldsymbol{\phi}_{a})}\Big]\triangleq\mathcal{L}\left(\boldsymbol{\theta},\boldsymbol{\phi}_{a}\right)`$ |  | (4) |

where, the Jensen’s inequality has been used, as it is classically done,
see \[[23](#bib.bib23)\]. The function
$`\mathcal{L}\left(\boldsymbol{\theta},\boldsymbol{\phi}_{a}\right)`$ is
called the evidence lower bound (ELBO) \[[23](#bib.bib23)\], because it
provides a lower bound on $`\log p({\bf s};\boldsymbol{\theta})`$. The
ELBO can be decomposed as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}\left(\boldsymbol{\theta},\boldsymbol{\phi}_{a}\right)=\mathbb{E}_{q({\bf z}|\mathbf{s};\boldsymbol{\phi}_{a})}\Big[\ln p\left(\mathbf{s}|\mathbf{z};\boldsymbol{\theta}\right)\Big]-\\
{{\cal D}_{KL}}\Big(q\left(\mathbf{z}|\mathbf{s};\boldsymbol{\phi}_{a}\right)\parallel p(\mathbf{z})\Big),
``` |  | (5) |

where, $`{{\cal D}_{KL}}(q\parallel p)`$ denotes the Kullback-Leibler
(KL) divergence between $`q`$ and $`p`$. The first term in the
right-hand side of
([5](#S2.E5 "In II-A Audio-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
evaluates the reconstruction quality of the decoder, and the second one
is a regularization term encouraging the variational posterior to remain
close to the prior. As the expectation in
([5](#S2.E5 "In II-A Audio-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
is computationally intractable, it is usually approximated by a single
sample drawn from
$`q({\bf z}|\mathbf{s};\boldsymbol{\phi}_{a})`$ \[[23](#bib.bib23)\].
Employing a so-called re-parameterization trick, the set of parameters
$`\left\{\boldsymbol{\theta},\boldsymbol{\phi}_{a}\right\}`$ is
estimated by a stochastic gradient ascent
algorithm \[[23](#bib.bib23)\]. Since all the parameters are inferred
using only audio data, the above model is called
A-VAE \[[30](#bib.bib30)\]. The associated architecture is shown in
Fig. [1](#S1.F1 "Fig. 1 ‣ I Introduction ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement") (top).

### II-B Visual-only VAE

A visual VAE (V-VAE) is proposed in \[[30](#bib.bib30)\], assuming the
same generative model as in
([1](#S2.E1 "In II-A Audio-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
and
([2](#S2.E2 "In II-A Audio-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")).
The difference with the A-VAE is that, here, the posterior
$`p(\mathbf{z}_{n}|\mathbf{s}_{n})`$ is approximated using visual-data
only:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
q(\mathbf{z}_{n}|\mathbf{v}_{n},\boldsymbol{\phi}_{v})=\mathcal{N}\Big(\boldsymbol{\mu}_{z}^{v}(\mathbf{v}_{n}),\text{diag}\Big(\boldsymbol{\sigma}_{z}^{v}(\mathbf{v}_{n})\Big)\Big),
``` |  | (6) |

where, $`{\mathbf{v}}_{n}\in{\mathbb{R}}^{M}`$ is an embedding for the
image of the speaker lips at frame $`n`$, and
$`\boldsymbol{\mu}_{z}^{v}(.):\mathbb{R}^{M}\mapsto\mathbb{R}^{L}`$ and
$`\boldsymbol{\sigma}_{z}^{v}(.):\mathbb{R}^{M}\mapsto\mathbb{R}_{+}^{L}`$
denote neural networks with parameters $`\boldsymbol{\phi}_{v}`$. Hence,
V-VAE attempts to reconstruct clean speech using latent variables
inferred from the lips images. The set of parameters,
$`\left\{\boldsymbol{\theta},\boldsymbol{\phi}_{v}\right\}`$, is
estimated in the same way as A-VAE.
Figure [1](#S1.F1 "Fig. 1 ‣ I Introduction ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement") (middle)
depicts the architecture of a V-VAE.

### II-C Audio-Visual VAE

An audio-visual VAE, called AV-VAE, is also presented
in \[[30](#bib.bib30)\] for speech modeling. The rationale of the AV-VAE
is to exploit the complementary between audio and visual modalities. The
associated generative model is defined as:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle{\bf s}_{n}|\mathbf{z}_{n};\mathbf{v}_{n}`$ | $`\displaystyle\sim\mathcal{N}_{c}\Big(\boldsymbol{0},\text{diag}\Big(\boldsymbol{\sigma}_{s}(\mathbf{z}_{n},\mathbf{v}_{n})\Big)\Big),`$ |  | (7) |
|  | $`\displaystyle\mathbf{z}_{n}|\mathbf{v}_{n}`$ | $`\displaystyle\sim\mathcal{N}\Big(\boldsymbol{\mu}_{z}^{av}(\mathbf{v}_{n}),\text{diag}\Big(\boldsymbol{\sigma}_{z}^{av}(\mathbf{v}_{n})\Big)\Big),`$ |  | (8) |

where,
$`\boldsymbol{\sigma}_{s}(.,.):\mathbb{R}^{L}\times\mathbb{R}^{M}\mapsto\mathbb{R}_{+}^{F}`$
is a neural network taking $`({\bf z}_{n},{\mathbf{v}}_{n})`$ as input.
Furthermore,
$`\boldsymbol{\mu}_{z}^{av}(.):\mathbb{R}^{M}\mapsto\mathbb{R}^{L}`$ and
$`\boldsymbol{\sigma}_{z}^{av}(.):\mathbb{R}^{M}\mapsto\mathbb{R}_{+}^{L}`$
are neural networks parameterizing the mean and variance of the prior
distribution of $`{\bf z}_{n}`$ using $`{\mathbf{v}}_{n}`$ as the input.
Note that throughout the paper, $`{\mathbf{v}}_{n}`$ is treated as a
deterministic piece of information, and so we do not model its
generative process. The variational approximation to
$`p(\mathbf{z}_{n}|\mathbf{s}_{n},{\mathbf{v}}_{n})`$ takes a similar
form as
([3](#S2.E3 "In II-A Audio-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
except that $`{\mathbf{v}}_{n}`$ is also fed to the associated neural
network. The architecture of an AV-VAE is shown in
Fig. [1](#S1.F1 "Fig. 1 ‣ I Introduction ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement") (bottom).

## III The Mixture of Inference Networks VAE

In this section, we aim to devise a framework able to choose the best
combination between the auditory and visual modalities in the encoder,
as opposed to systematically using both encodings through tight fusion,
as done in AV-VAE. To achieve this goal, we propose a probabilistic
mixture of an audio and a visual encoder, and name it mixture of
inference networks VAE (MIN-VAE). Intuitively, the model learns to infer
to which extent the approximate posterior of $`{\bf z}_{n}`$ should be
audio- or visual-based. The overall architecture is depicted in
Fig. [2](#S3.F2 "Fig. 2 ‣ III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement").
In the following, we introduce the mathematical formulations associated
with the proposed MIN-VAE. The generative model is presented in
Subsection [III-A](#S3.SS1 "III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"),
which uses a mixture of two different Gaussian distributions for the
prior of the latent variables, as opposed to standard VAE and to the
models in the previous section that use a standard Gaussian
distribution. This innovative choice is motivated to ease the task of
the generative model. Indeed, by modeling two different prior
distributions, the decoder network can easily understand if the sample
is audio-based or visual-based.
Subsection [III-B](#S3.SS2 "III-B The Posterior Distribution ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")
proposes a variational distribution to approximate the intractable
posterior of the latent variables. This variational distribution is then
used in
Subsection [III-C](#S3.SS3 "III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")
to derive the training algorithm for the overall MIN-VAE. Finally, noise
modelling for speech enhancement at test time is discussed in
Subsection [III-D](#S3.SS4 "III-D Noise Modeling ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement").

### III-A The Generative Model

We assume that each latent code is generated either from an audio or
from a visual prior. We model this with a mixing variable
$`\alpha_{n}\in\{0,1\}`$ describing whether the latent code
$`{\bf z}_{n}`$ corresponds to the audio or to the visual prior. Once
the latent code is generated from the corresponding prior, the speech
frame $`{\bf s}_{n}`$ follows a complex Gaussian distribution with the
variance computed by the decoder. We recall that the variance is a
non-linear transformation of the latent code.

MIN-VAE

![Refer to caption](1912.10647v4/enc_av_vae_dec.png)

Fig. 2: Architecture of the proposed mixture of inference networks VAE
(MIN-VAE). A mixture of an audio- and a visual-based encoder is used to
approximate the intractable posterior distribution of the latent
variables.

Formally, each STFT time frame $`{\bf s}_{n}`$ is modeled as:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle{\bf s}_{n}|\mathbf{z}_{n};{\mathbf{v}}_{n}`$ | $`\displaystyle\sim\mathcal{N}_{c}\Big(\boldsymbol{0},\text{diag}\Big(\boldsymbol{\sigma}_{s}(\mathbf{z}_{n},{\mathbf{v}}_{n})\Big)\Big),`$ |  | (9) |
|  | $`\displaystyle{\bf z}_{n}|\alpha_{n}`$ | $`\displaystyle\sim\Big[{\cal N}(\boldsymbol{\mu}_{a},\sigma_{a}{\bf I})\Big]^{\alpha_{n}}\cdot\Big[{\cal N}(\boldsymbol{\mu}_{v},\sigma_{v}{\bf I})\Big]^{1-\alpha_{n}},`$ |  | (10) |
|  | $`\displaystyle\alpha_{n}`$ | $`\displaystyle\sim\pi^{\alpha_{n}}\times(1-\pi)^{1-\alpha_{n}},`$ |  | (11) |

where the audio and visual priors are parametrized by
$`(\boldsymbol{\mu}_{a},\sigma_{a})`$ and
$`(\boldsymbol{\mu}_{v},\sigma_{v})`$ respectively, and $`\alpha_{n}`$
is assumed to follow a Bernoulli distribution with parameter $`\pi`$. We
propose two versions of this architecture, namely: MIN-VAE-v1 where the
decoder
([9](#S3.E9 "In III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
takes the same form as
([7](#S2.E7 "In II-C Audio-Visual VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
and uses explicitly visual information (see
Fig. [2](#S3.F2 "Fig. 2 ‣ III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
and MIN-VAE-v2 where the decoder
([9](#S3.E9 "In III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
takes the same form as
([1](#S2.E1 "In II-A Audio-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
and does not use explicitly visual information. In both cases the
parameters of the decoder are denoted by $`\boldsymbol{\theta}`$. The
derivations will be done for the general case, that is MIN-VAE-v1.

### III-B The Posterior Distribution

In order to estimate the parameters of the generative model described
above, i.e.
$`\boldsymbol{\psi}=\left\{\boldsymbol{\mu}_{a},\boldsymbol{\mu}_{v},\sigma_{a},\sigma_{v}\right\}`$,
$`\boldsymbol{\theta}`$, and $`\pi`$, we follow a maximum likelihood
procedure. To derive it, we need to compute the posterior of the latent
variables:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p({\bf z}_{n},\alpha_{n}|{\bf s}_{n};{\mathbf{v}}_{n})=p({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n})\cdot p(\alpha_{n}|{\bf s}_{n};{\mathbf{v}}_{n}).
``` |  | (12) |

The individual factors in the right-hand side of the above equation
cannot be computed in closed-form, due to the non-linear generative
model. As similarly done in VAE, we pursue an amortized inference
approach to approximate
$`p({\bf z}_{n}|{\bf s}_{n},{\mathbf{v}}_{n},\alpha_{n})`$ with a
parametric Gaussian distribution defined as follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})=\begin{cases}q({\bf z}_{n}|{\bf s}_{n};\boldsymbol{\phi}_{a})&\alpha_{n}=1,\\
q({\bf z}_{n}|{\mathbf{v}}_{n};\boldsymbol{\phi}_{v})&\alpha_{n}=0,\end{cases}
``` |  | (13) |

in which,
$`\boldsymbol{\phi}=\left\{\boldsymbol{\phi}_{a},\boldsymbol{\phi}_{v}\right\}`$,
and $`\boldsymbol{\phi}_{a}`$ and $`\boldsymbol{\phi}_{v}`$ denote the
parameters of the associated audio and visual inference neural networks,
taking the same architectures as those in
([3](#S2.E3 "In II-A Audio-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
and
([6](#S2.E6 "In II-B Visual-only VAE ‣ II VAE-based Speech Modeling ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
respectively. For the posterior of $`\alpha_{n}`$, i.e.
$`p(\alpha_{n}|{\bf s}_{n};{\mathbf{v}}_{n})`$, we resort to a
variational approximation, denoted $`r(\alpha_{n})`$. Put it all
together, we have the following approximate posterior:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})\cdot r(\alpha_{n})\approx p({\bf z}_{n},\alpha_{n}|{\bf s}_{n};{\mathbf{v}}_{n}).
``` |  | (14) |

### III-C Training the MIN-VAE

In order to train the MIN-VAE, we devise an optimization procedure
alternating between estimating
$`\boldsymbol{\Theta}=\left\{\boldsymbol{\phi},\boldsymbol{\theta},\boldsymbol{\psi},\pi\right\}`$
and updating the variational posterior $`r`$. To do so, we first need to
give an expression of the exact posterior distribution, so as to write
the optimization function, namely the KL-divergence between the
approximate variational posterior and the true posterior. To write the
exact posterior, we will use the decomposition of the generative model
in
equations ([9](#S3.E9 "In III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
– ([11](#S3.E11 "In III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
and recall the definition
$`{\bf s}=\left\{{\bf s}_{n}\right\}_{n=1}^{N_{tr}}`$, and $`{\bf z}`$,
and define $`\alpha`$ and $`{\mathbf{v}}`$ analogously. The full
posterior of the latent variables writes:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle p({\bf z},{\mbox{\boldmath$\alpha$}}|{\bf s};{\mathbf{v}},\boldsymbol{\theta})`$ | $`\displaystyle=\frac{p({\bf s},{\bf z},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\theta})}{p({\bf s};{\mathbf{v}},\boldsymbol{\theta})}`$ |  |  |
|  |  | $`\displaystyle=\frac{p({\bf s}|{\bf z};{\mathbf{v}},\boldsymbol{\theta})p({\bf z}|{\mbox{\boldmath$\alpha$}})p({\mbox{\boldmath$\alpha$}})}{p({\bf s};{\mathbf{v}},\boldsymbol{\theta})}.`$ |  | (15) |

We then target the KL-divergence between the approximate posterior and
the true posterior which reads:

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle{\cal D}_{KL}\Big(q({\bf z}|{\bf s},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\phi})r({\mbox{\boldmath$\alpha$}})\Big\|p({\bf z},{\mbox{\boldmath$\alpha$}}|{\bf s};{\mathbf{v}},\boldsymbol{\theta})\Big)=`$ |  |  |
|  |  | $`\displaystyle\sum_{{\mbox{\boldmath$\alpha$}}}\int_{\mathbb{Z}}q({\bf z}|{\bf s},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\phi})r({\mbox{\boldmath$\alpha$}})\log\frac{q({\bf z}|{\bf s},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\phi})r({\mbox{\boldmath$\alpha$}})p({\bf s};{\mathbf{v}},\boldsymbol{\theta})}{p({\bf s}|{\bf z};{\mathbf{v}},\boldsymbol{\theta})p({\bf z}|{\mbox{\boldmath$\alpha$}})p({\mbox{\boldmath$\alpha$}})}\textrm{d}{\bf z}`$ |  |  |
|  |  | $`\displaystyle=-\mathcal{L}(\boldsymbol{\Theta},r)+\log p({\bf s};{\mathbf{v}},\boldsymbol{\theta})\geq 0,`$ |  | (16) |

where

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}(\boldsymbol{\Theta},r)=\\
\sum_{{\mbox{\boldmath$\alpha$}}}\int_{\mathbb{Z}}q({\bf z}|{\bf s},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\phi})r({\mbox{\boldmath$\alpha$}})\log\frac{p({\bf s}|{\bf z};{\mathbf{v}},\boldsymbol{\theta})p({\bf z}|{\mbox{\boldmath$\alpha$}})p({\mbox{\boldmath$\alpha$}})}{q({\bf z}|{\bf s},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\phi})r({\mbox{\boldmath$\alpha$}})}\textrm{d}{\bf z}.
``` |  | (17) |

From
([16](#S3.E16 "In III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
we can see that
$`\log p({\bf s};{\mathbf{v}},\boldsymbol{\theta})\geq\mathcal{L}(\boldsymbol{\Theta},r)`$.
Therefore, instead of maximizing the intractable data log-likelihood
$`\log p({\bf s};{\mathbf{v}},\boldsymbol{\theta})`$, we maximize its
lower-bound, i.e. $`\mathcal{L}(\boldsymbol{\Theta},r)`$, or
equivalently:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\boldsymbol{\Theta}^{*},r^{*}=\operatornamewithlimits{argmin}_{\boldsymbol{\Theta},r}-\mathcal{L}(\boldsymbol{\Theta},r)
``` |  | (18) |

subject to the constraint that $`r`$ integrates to one. We solve this
problem by alternately optimizing the cost over $`r`$ and
$`\boldsymbol{\Theta}`$. In the following, the two optimization steps
are discussed.

#### III-C1 Optimizing w.r.t. $`r({\mbox{\boldmath$\alpha$}})`$

With $`\boldsymbol{\Theta}`$ being fixed to its current estimate,
solving ([18](#S3.E18 "In III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
boils down to:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\min_{r}\sum_{\alpha_{n}}r_{n}(\alpha_{n})\Big[\log\frac{r_{n}(\alpha_{n})}{p(\alpha_{n})}+J_{n}(\alpha_{n})\Big],\forall n,
``` |  | (19) |

meaning that the optimal $`r`$ is separable on $`n`$, where,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
J_{n}(\alpha_{n})=\\
\int_{\mathbb{Z}}q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})\log\frac{q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})}{p({\bf s}_{n}|{\bf z}_{n};{\mathbf{v}}_{n},\boldsymbol{\theta})p({\bf z}_{n}|\alpha_{n})}\textrm{d}{\bf z}_{n}=\\
{\cal D}_{KL}\Big(q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})\Big\|p({\bf z}_{n}|\alpha_{n})\Big)-\\
\mathbb{E}_{q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})}\Big[\log p({\bf s}_{n}|{\bf z}_{n};{\mathbf{v}}_{n},\boldsymbol{\theta})\Big].
``` |  | (20) |

Using calculus of variations, we find that
$`r_{n}(\alpha_{n})\propto p(\alpha_{n})\exp\big(-J_{n}(\alpha_{n})\big)`$,
which is a Bernoulli distribution. To find the associated parameter, we
need to compute $`J_{n}(\alpha_{n})`$. Since the expectation involved in
([20](#S3.E20 "In III-C1 Optimizing w.r.t. 𝑟(𝜶) ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
is intractable to compute, we approximate it using a single sample
denoted $`{\bf z}_{n}^{\alpha_{n}}`$ drawn from
$`q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})`$,
obtaining:

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\tilde{J}_{n}(\alpha_{n})=`$ |  |  |
|  |  | $`\displaystyle{\cal D}_{KL}\Big(q({\bf z}_{n}|{\bf s}_{n},\alpha_{n};{\mathbf{v}}_{n},\boldsymbol{\phi})\Big\|p({\bf z}_{n}|\alpha_{n})\Big)-\log p({\bf s}_{n}|{\bf z}_{n}^{\alpha_{n}};{\mathbf{v}}_{n},\boldsymbol{\theta}),`$ |  | (21) |

The parameter of the Bernoulli distribution then takes the following
form:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi_{n}=g\Big(\tilde{J}_{n}(\alpha_{n}=0)-\tilde{J}_{n}(\alpha_{n}=1)+\log\frac{\pi}{1-\pi}\Big),
``` |  | (22) |

where $`g(x)=1/(1+\exp(-x))`$ is the sigmoid function. Computations of
the KL divergence terms are provided in
Appendix [A](#A1 "Appendix A KL divergence computation ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement").

#### III-C2 Optimizing w.r.t. $`\boldsymbol{\Theta}`$

With $`r`$ being fixed to its current estimate, from
([18](#S3.E18 "In III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
we can write the optimization over $`\boldsymbol{\Theta}`$ as:

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\min_{\boldsymbol{\Theta}}~\sum_{{\mbox{\boldmath$\alpha$}}}\int_{\mathbb{Z}}q({\bf z}|{\bf s},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\phi})r({\mbox{\boldmath$\alpha$}})\log\frac{q({\bf z}|{\bf s},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\boldsymbol{\phi})r({\mbox{\boldmath$\alpha$}})}{p({\bf s}|{\bf z};{\mathbf{v}},\boldsymbol{\theta})p({\bf z}|{\mbox{\boldmath$\alpha$}})p({\mbox{\boldmath$\alpha$}})}\textrm{d}{\bf z}`$ |  |  |
|  |  | $`\displaystyle=\min_{\boldsymbol{\Theta}}~\sum_{n=0}^{N_{tr}}\pi_{n}\Big({\cal D}_{KL}\Big(q({\bf z}_{n}|{\bf s}_{n};\boldsymbol{\phi}_{a})\Big\|p({\bf z}_{n}|\alpha_{n}=1)\Big)-`$ |  |  |
|  |  | $`\displaystyle\mathbb{E}_{q({\bf z}_{n}|{\bf s}_{n};\boldsymbol{\phi}_{a})}\Big[\log p({\bf s}_{n}|{\bf z}_{n};{\mathbf{v}}_{n},\boldsymbol{\theta})\Big]\Big)+`$ |  |  |
|  |  | $`\displaystyle(1-\pi_{n})\Big({\cal D}_{KL}\Big(q({\bf z}_{n}|{\mathbf{v}}_{n};\boldsymbol{\phi}_{v})\Big\|p({\bf z}_{n}|\alpha_{n}=0)\Big)-`$ |  |  |
|  |  | $`\displaystyle\mathbb{E}_{q({\bf z}_{n}|{\mathbf{v}}_{n};\boldsymbol{\phi}_{v})}\Big[\log p({\bf s}_{n}|{\bf z}_{n};{\mathbf{v}}_{n},\boldsymbol{\theta})\Big]\Big)+{{\cal D}_{KL}}\Big(r\left(\alpha_{n}\right)\parallel p(\alpha_{n})\Big).`$ |  | (23) |

As before, the expectations involved in the above equation are
approximated with a single sample drawn from the associated posteriors.
After computing the cost function, the parameters are updated using a
re-parametrization trick along with a stochastic gradient descent
algorithm, e.g. the Adam optimizer. Finally, optimizing
([23](#S3.E23 "In III-C2 Optimizing w.r.t. 𝚯 ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
over $`\pi`$ leads to minimizing the following KL-divergence:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
{{\cal D}_{KL}}\Big(r\left(\alpha_{n}\right)\parallel p(\alpha_{n})\Big)=\pi_{n}\log\frac{\pi_{n}}{\pi}+(1-\pi_{n})\log\frac{1-\pi_{n}}{\pi},
``` |  | (24) |

yielding

|     |                                                 |     |      |
|-----|-------------------------------------------------|-----|------|
|     |
       ``` math
       \pi=\frac{1}{N_{tr}}\sum_{n=1}^{N_{tr}}\pi_{n}.
       ```                                              |     | (25) |

Now, with the derived variational inference formulas, we obtain the
inference mixture for the MIN-VAE:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle p({\bf z}_{n}|{\bf s}_{n};{\mathbf{v}}_{n})`$ | $`\displaystyle=\pi_{n}\,\mathcal{N}\Big(\boldsymbol{\mu}_{z}^{a}({\bf s}_{n}),\text{diag}\Big(\boldsymbol{\sigma}_{z}^{a}(\mathbf{s}_{n})\Big)\Big)`$ |  | (26) |
|  |  | $`\displaystyle+(1-\pi_{n})\,\mathcal{N}\Big(\boldsymbol{\mu}_{z}^{v}(\mathbf{v}_{n}),\text{diag}\Big(\boldsymbol{\sigma}_{z}^{v}(\mathbf{v}_{n})\Big)\Big).`$ |  | (27) |

The overall training algorithm then consists of alternating the
variational distribution update of $`\alpha_{n}`$ via
([22](#S3.E22 "In III-C1 Optimizing w.r.t. 𝑟(𝜶) ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
the update of $`\boldsymbol{\phi}`$, $`\boldsymbol{\theta}`$, and
$`\boldsymbol{\psi}`$ via stochastic gradient descent of
([23](#S3.E23 "In III-C2 Optimizing w.r.t. 𝚯 ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
and the update of $`\pi`$ using
([25](#S3.E25 "In III-C2 Optimizing w.r.t. 𝚯 ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")).

### III-D Noise Modeling

At test time, once the MIN-VAE is trained, the STFT time frames of the
observed noisy speech are modeled as
$`{\bf x}_{n}={\bf s}_{n}+{\bf b}_{n}`$, for $`n=0,\ldots,N-1`$, with
$`{\bf b}_{n}`$ denoting noise STFT time frame. For the probabilistic
modeling of $`{\bf s}_{n}`$, we use the generative model trained on
clean data (i.e. the previous section). For $`{\bf b}_{n}`$, the
following NMF based model is considered \[[16](#bib.bib16)\]:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
{\bf b}_{n}\sim\mathcal{N}\Big(\boldsymbol{0},\text{diag}\Big({\bf W}\boldsymbol{h}_{n}\Big)\Big),
``` |  | (28) |

where, $`{\bf W}\in{\mathbb{R}}_{+}^{F\times K}`$, and
$`\boldsymbol{h}_{n}`$ denotes the $`n`$-th column of
$`{\bf H}\in{\mathbb{R}}_{+}^{K\times N}`$. The parameters, i.e.
$`\left\{{\bf W},{\bf H}\right\}`$, as well as the unknown speech are
then estimated following a variational inference
method \[[33](#bib.bib33)\]. This strategy is inspired by the recent
literature \[[16](#bib.bib16), [31](#bib.bib31)\]. The details are
provided in
Appendix [B](#A2 "Appendix B Speech enhancement ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement").

## IV Experiments

In this section, we aim to evaluate the speech enhancement performance
of different VAE architectures, including A-VAE \[[16](#bib.bib16)\],
V-VAE \[[30](#bib.bib30)\], AV-VAE  \[[30](#bib.bib30)\], and the
proposed MIN-VAE. To measure the performance, we use standard scores,
including the SDR (SDR) \[[34](#bib.bib34)\], the PESQ (PESQ)
 \[[35](#bib.bib35)\], and the STOI (STOI) \[[36](#bib.bib36)\]. SDR is
measured in decibels (dB), while PESQ and STOI values lie in the
intervals $`[-0.5,4.5]`$ and $`[0,1]`$, respectively (the higher the
better). For each measure, we report the averaged difference between the
output value (evaluated on the enhanced speech signal) and the input
value (evaluated on the noisy/unprocessed mixture signal). The average
values of SDR, PESQ, and STOI computed on the input noisy speech signals
are reported in
Table [II](#S4.T2 "TABLE II ‣ Architecture and training details ‣ IV-A Experimental Set-up ‣ IV Experiments ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement").

### IV-A Experimental Set-up

##### Dataset

We use the NTCD-TIMIT dataset \[[37](#bib.bib37)\], which contains AV
(AV) recordings from $`56`$ English speakers with an Irish accent,
uttering $`5488`$ different TIMIT sentences \[[38](#bib.bib38)\]. The
visual data consist of 30 FPS videos of lips ROI. Each frame (ROI) is of
size 67$`\times`$67 pixels. The speech signal is sampled at $`16`$ kHz,
and the audio spectral features are computed using an STFT window of
64 ms ($`1024`$ samples per frame) with 47.9% overlap, hence $`F=513`$.
The dataset is divided into $`39`$ speakers for training, $`8`$ speakers
for validation, and $`9`$ speakers for testing, as proposed
in \[[37](#bib.bib37)\]. The test set includes about $`1`$ hour noisy
speech, along with their corresponding lips ROIs, with six different
noise types, including LR (LR), White, Cafe, Car, Babble, and Street,
with noise levels: $`\left\{-15,-10,-5,0,5,10,15\right\}`$ dB.

##### Architecture and training details

The generative networks (decoders) of A-VAE and V-VAE consist of a
single hidden layer with 128 nodes and hyperbolic tangent activations.
The dimension of the latent space is $`L=32`$. The A-VAE encoder has a
single hidden layer with $`128`$ nodes and hyperbolic tangent
activations. The V-VAE encoder is similar to the A-VAE encoder, except
for extracting visual features, embedding lip ROI into a feature vector
$`\mathbf{v}_{n}\in\mathbb{R}^{M}`$, with $`M=128`$. This is composed of
two fully-connected layers with $`512`$ and $`128`$ nodes. The dimension
of the input corresponds to a single vectorized frame, namely
$`4489=67\times 67`$. AV-VAE combines the architectures of A-VAE and
V-VAE as illustrated in
Fig. [1](#S1.F1 "Fig. 1 ‣ I Introduction ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement").
The audio and the visual encoders in
Fig. [2](#S3.F2 "Fig. 2 ‣ III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")
share also the same architectures as those of A-VAE and V-VAE encoders,
respectively.

To have a fair comparison, we fine-tunned the A-VAE and V-VAE
of \[[30](#bib.bib30)\], which have been trained with a standard
Gaussian prior for the latent variables, by using a parametric Gaussian
prior, as the ones in
([10](#S3.E10 "In III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")).
The decoder parameters of MIN-VAE-v1 and MIN-VAE-v2 (see
Section [III-A](#S3.SS1 "III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
are initialized with those of the pretrained AV-VAE and A-VAE,
respectively. The parameters of the audio and the visual encoders are
also initialized with the corresponding parameters in the pretrained
A-VAE and V-VAE encoders. Then, all the parameters are fine-tuned using
the Adam optimizer \[[39](#bib.bib39)\] with a step size of $`10^{-4}`$,
for $`100`$ epochs, and with a batch-size of $`128`$.

We also considered another way to combine A-VAE with V-VAE, in which
these two VAE architectures share the same decoder, and they are trained
alternately. That is, at each epoch, the shared decoder is trained using
latent samples coming from either the encoder of A-VAE or that of V-VAE.
As a result, at each epoch, only the encoder parameters of the
corresponding VAE, i.e. A-VAE or V-VAE, are updated while those of the
other encoder are kept fixed. This training strategy is considered as a
baseline where we do not use a mixture model for the encoder to
automatically choose between the audio and the visual encoders. Instead,
an alternating sampling from the two encoders is performed. We refer to
the resulting VAE as MIN-VAE-v3. A description of all the proposed VAE

##### Speech enhancement parameters

For all the methods, the rank of $`{\bf W}`$ and $`{\bf H}`$ in the

the visual-encoders are used.

### IV-B Results and Discussion

summarizes the results of all the VAE architectures, in terms of SDR,

algorithms. MIN-VAE-v3 outperforms other methods in terms of SDR and
PESQ. Nevertheless, its intelligibility improvement is not satisfactory.
The proposed MIN-VAE methods also outperform A-VAE, especially at high
noise levels. As explained earlier, this might be due to the facts that
the proposed networks efficiently make use of the robust initialization
provided by the visual data, and also by the richer generative models
(decoders) which are trained using both audio and visual latent codes.
At high noise levels, MIN-VAE-v1 outperforms MIN-VAE-v2, implying the
importance of using visual modality in the decoder when the input speech
is very noisy. A related observation is that, MIN-VAE-v2 outperforms
both MIN-VAE-v1 and AV-VAE when the level of noise is low, implying that
the visual features in the generative model contribute mainly in high
noise regimes. The average posterior probability of the $`\alpha_{n}`$
variable given in

is $`0.96`$, implying that the contribution of the audio encoder in

is worth mentioning that in the low noise regime, the amount of
performance improvement is decreasing for all the methods, as the speech
signals are already clean enough.

Regarding noise type, we see that the algorithms perform very
differently. The Babble noise is the most difficult noise environment
according to the bottom row of
Fig. [3](#S3.F3 "Fig. 3 ‣ III-C2 Optimizing w.r.t. 𝚯 ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement").
In terms of SDR, all the methods show their best performance for the Car

Finally, in terms of STOI, MIN-VAE-v2 achieves the best performance for
the Car noise.

To encourage the proposed MIN-VAE networks to make use of the visual
data in the encoder more efficiently, we added some uniformly
distributed noise, with the SNR being about 0 dB and fixed during

fed to the audio encoders. We also added noise to the audio encoder’s
inputs of A-VAE and AV-VAE. However, no performance improvements were
observed. The amount of noise and percentage of noisy frames have been

presents the results of this experiment. A clear performance improvement
is observed compared to

especially for MIN-AVE-v2. With this new training, the proposed

## V Conclusions

Inspired by the importance of latent variable initialization for
VAE-based speech enhancement, and as another way than simple
concatenation to effectively fuse audio and visual modalities in the
encoder of VAE, we proposed a mixture of inference (audio and visual
encoders) networks, which are jointly trained with a shared generative
network. The overall architecture is named MIN-VAE. A variational
inference approach was proposed to estimate the parameters of the model.
At test phase of the speech enhancement, the initialization of the
latent variables, as required by the MCEM inference method, is based on
the visual modality, which is assumed to be clean in contrast to audio
data. As such, it provides a better performance than initializing with
noisy audio data. This is confirmed by our experiments, comparing
different VAE architectures.

For future works, dynamical VAE architectures \[[40](#bib.bib40)\] will
be investigated, which take into account the temporal correlation
between audio and visual frames. This is expected to better handle
visual modality, thus achieving superior performance compared to
audio-only VAE. Furthermore, we will consider robustifying the proposed
algorithms to noisy visual data, e.g. by using the mixture idea
dveleoped in \[[32](#bib.bib32)\]. Finally, reducing the computational
complexity of the inference will be another promising research
direction.

## Appendix A KL divergence computation

The KL divergence between two Gaussian distributions is given by the
following lemma:

###### Lemma 1.

Let
$`p_{1}({\bf x};{\mbox{\boldmath$\mu$}}_{1},{\mbox{\boldmath$\Sigma$}}_{1})`$
and
$`p_{2}({\bf x};{\mbox{\boldmath$\mu$}}_{2},{\mbox{\boldmath$\Sigma$}}_{2})`$
be two multivariate Gaussian distributions in $`{\mathbb{R}}^{n}`$.
Then, the KL divergence between $`p_{1}`$ and $`p_{2}`$ reads:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
{\cal D}_{KL}(p_{1}\|p_{2})=\frac{1}{2}\Big(\log\frac{\det{\mbox{\boldmath$\Sigma$}}_{2}}{\det{\mbox{\boldmath$\Sigma$}}_{1}}-n+\trace({\mbox{\boldmath$\Sigma$}}_{2}^{-1}{\mbox{\boldmath$\Sigma$}}_{1})+\\
({\mbox{\boldmath$\mu$}}_{2}-{\mbox{\boldmath$\mu$}}_{1})^{T}{\mbox{\boldmath$\Sigma$}}_{2}^{-1}({\mbox{\boldmath$\mu$}}_{2}-{\mbox{\boldmath$\mu$}}_{1})\Big).
``` |  | (29) |

Utilizing the above lemma, we can write the KL divergence term in
([21](#S3.E21 "In III-C1 Optimizing w.r.t. 𝑟(𝜶) ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
(for $`\alpha_{n}=1`$) as follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\hskip-11.38109pt{{\cal D}_{KL}}\Big(q({\bf z}_{n}|{\bf s}_{n};\boldsymbol{\phi}_{a})\parallel p(\mathbf{z}_{n}|\alpha_{n})\Big)=\frac{1}{2}\log\frac{\sigma_{a}^{L}}{\Big|\text{diag}\Big(\boldsymbol{\sigma}_{z}^{a}(\mathbf{s}_{n})\Big)\Big|}-\\
+\frac{{\mbox{{trace}}}\Big(\text{diag}\Big(\boldsymbol{\sigma}_{z}^{a}(\mathbf{s}_{n})\Big)\Big)+\|\boldsymbol{\mu}_{z}^{a}({\bf s}_{n})-{\mbox{\boldmath$\mu$}}_{a}\|^{2}}{2\sigma_{a}}-\frac{L}{2},
``` |  | (30) |

and analogously for the vision-based term ($`\alpha_{n}=0`$).

## Appendix B Speech enhancement

The generative model is given in
([9](#S3.E9 "In III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"))
–
([11](#S3.E11 "In III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
where all the parameters except $`\pi`$ have already been trained on
clean audio and visual data. The observations are noisy STFT frames
$`{\bf x}=\left\{{\bf x}_{n}\right\}_{n=0}^{N-1}`$, as well as the
visual data
$`{\mathbf{v}}=\left\{{\mathbf{v}}_{n}\right\}_{n=0}^{N-1}`$. The latent
variables of the model are
$`{\bf s}=\left\{{\bf s}_{n}\right\}_{n=0}^{N-1}`$,
$`{\bf z}=\left\{{\bf z}_{n}\right\}_{n=0}^{N-1}`$, and
$`{\mbox{\boldmath$\alpha$}}=\left\{\alpha_{n}\right\}_{n=0}^{N-1}`$.
Furthermore, the parameters of the model are
$`\Theta=\left\{\mathbf{W},\mathbf{H},\pi\right\}`$.

### B-A Parameters Estimation

The full posterior is written as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p({\bf s}_{n},{\bf z}_{n},\alpha_{n}|{\bf x}_{n};{\mathbf{v}}_{n},\Theta)\propto p({\bf x}_{n},{\bf s}_{n},{\bf z}_{n},\alpha_{n};{\mathbf{v}}_{n},\Theta)=\\
p({\bf x}_{n}|{\bf s}_{n};\Theta)\times p({\bf s}_{n}|{\bf z}_{n};{\mathbf{v}}_{n})\times p({\bf z}_{n}|\alpha_{n})\times p(\alpha_{n})
``` |  | (31) |

To estimate the parameter set, we develop a variational inference
method \[[33](#bib.bib33)\], where in the variational expectation step
(VE-step), the above intractable posterior is approximated by a
variational distribution $`r({\bf s}_{n},{\bf z}_{n},\alpha_{n})`$, as
similarly done in \[[31](#bib.bib31)\]. The maximization step (M-step)
performs parameters update using the obtained variational distributions.
We assume that $`r`$ factorizes as follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
r({\bf s}_{n},{\bf z}_{n},\alpha_{n})=r({\bf s}_{n})\times r({\bf z}_{n})\times r(\alpha_{n}).
``` |  | (32) |

where for notational convenience, we have omitted the dependence on
$`\Theta`$. Denoting the current estimate of the parameters as
$`\Theta^{old}`$, the VEM approach consists of iterating between the
VE-steps and the M-step, which are detailed below.

#### B-A1 VE-$`r({\bf s}_{n})`$ step

The variational distribution of $`{\bf s}_{n}`$ is computed
as \[[33](#bib.bib33)\]:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle r({\bf s}_{n})\propto\exp\Big(`$ | $`\displaystyle\mathbb{E}_{r({\bf z}_{n})\cdot r(\alpha_{n})}\Big[\log p({\bf x}_{n},{\bf s}_{n},{\bf z}_{n},\alpha_{n};{\mathbf{v}}_{n},\Theta^{old})\Big]\Big)`$ |  |  |
|  | $`\displaystyle=\exp\Big(`$ | $`\displaystyle-\sum_{f}\Big[\frac{|x_{fn}-s_{fn}|^{2}}{({\bf W}{\bf H})_{fn}}+\frac{|s_{fn}|^{2}}{\gamma_{fn}}\Big]\Big),`$ |  | (33) |

where,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\gamma_{fn}^{-1}=\mathbb{E}_{r({\bf z}_{n})}\left[\frac{1}{{\sigma}_{s,f}(\mathbf{z}_{n}^{(d)},{\mathbf{v}}_{n})}\right]\approx\frac{1}{D}\sum_{d=1}^{D}\frac{1}{{\sigma}_{s,f}(\mathbf{z}_{n}^{(d)},{\mathbf{v}}_{n})},
``` |  | (34) |

and $`\left\{{\bf z}_{n}^{(d)}\right\}_{d=1}^{D}`$ is a sequence sampled
from $`r({\bf z}_{n})`$. From
([33](#A2.E33 "In B-A1 VE-𝑟(𝐬_𝑛) step ‣ B-A Parameters Estimation ‣ Appendix B Speech enhancement ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
we can see that $`r(s_{fn})={\cal N}_{c}(m_{fn},\nu_{fn})`$, where:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\begin{cases}m_{fn}&=\frac{\gamma_{fn}}{\gamma_{fn}+\left(\mathbf{W}\mathbf{H}\right)_{fn}}\cdot x_{fn}\\
\nu_{fn}&=\frac{\gamma_{fn}\cdot\left(\mathbf{W}\mathbf{H}\right)_{fn}}{\gamma_{fn}+\left(\mathbf{W}\mathbf{H}\right)_{fn}}\end{cases}.
``` |  | (35) |

#### B-A2 VE-$`r({\bf z}_{n})`$ step

The variational distribution of $`{\bf z}_{n}`$ can be computed by the
following standard formula:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle r({\bf z}_{n})`$ | $`\displaystyle\propto\exp\Big(\mathbb{E}_{r({\bf s}_{n})\cdot r(\alpha_{n})}\Big[\log p({\bf x}_{n},{\bf s}_{n},{\bf z}_{n},\alpha_{n};{\mathbf{v}}_{n},\Theta^{old})\Big]\Big)`$ |  |  |
|  |  | $`\displaystyle\propto\exp\Big(\sum_{f}-\log\Big({{\sigma}_{s,f}(\mathbf{z}_{n},{\mathbf{v}}_{n})}\Big)-\frac{|m_{fn}|^{2}+\nu_{fn}}{{\sigma}_{s,f}(\mathbf{z}_{n},{\mathbf{v}}_{n})}`$ |  |  |
|  |  | $`\displaystyle+\sum_{\alpha_{n}\in\left\{0,1\right\}}r(\alpha_{n})\cdot\Big[\log p({\bf z}_{n}|\alpha_{n})\Big]\Big)\triangleq\tilde{r}({\bf z}_{n})`$ |  | (36) |

This gives us an unnormalized distribution $`\tilde{r}({\bf z}_{n})`$
whose normalization constant cannot be computed in closed-from, due to
the non-linear terms. However, we use the Metropolis-Hastings
algorithm \[[33](#bib.bib33)\] to sample from it. To that end, we need
to start with an initialization, $`{\bf z}^{(0)}`$. At the beginning of
the inference, $`{\bf z}^{(0)}`$ is set to be the posterior mean in the
output of the visual-encoder, i.e. the bottom-left network in
Fig. [2](#S3.F2 "Fig. 2 ‣ III-A The Generative Model ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement"),
where $`{\mathbf{v}}_{n}`$ is given as the input. Then, a candidate
sample denoted $`{\bf z}^{(c)}`$ is obtained by sampling from a proposal
distribution, usually chosen to be a Gaussian:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
{\bf z}^{(c)}|{\bf z}^{(0)}\sim{\cal N}({\bf z}^{(0)},\epsilon{\bf I}),
``` |  | (37) |

where, $`\epsilon>0`$ controls the speed of convergence. Then,
$`{\bf z}^{(c)}`$ is set to be the next sample $`{\bf z}^{(1)}`$ with
the following probability:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p=\min\Big(1,\frac{\tilde{r}({\bf z}^{(c)})}{\tilde{r}({\bf z}^{(0)})}\Big).
``` |  | (38) |

That means, some $`u`$ is drawn from a uniform distribution between
$`0`$ and $`1`$. Then, if $`u<p`$, the sample is accepted and
$`{\bf z}^{(1)}={\bf z}^{(c)}`$. Otherwise, it is rejected and
$`{\bf z}^{(1)}={\bf z}^{(0)}`$. This procedure is repeated until the
required number of samples is achieved. The first few samples are
usually discarded, as they are not so reliable.

#### B-A3 VE-$`r(\alpha_{n})`$ step

The variational distribution of $`\alpha_{n}`$ is computed as:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle r(\alpha_{n})`$ | $`\displaystyle\propto\exp\Big(\mathbb{E}_{r({\bf s}_{n})\cdot r({\bf z}_{n})}\Big[\log p({\bf x}_{n},{\bf s}_{n},{\bf z}_{n},\alpha_{n};{\mathbf{v}}_{n},\Theta^{old})\Big]\Big)`$ |  |  |
|  |  | $`\displaystyle\propto p(\alpha_{n})\times\exp\Big(\mathbb{E}_{r({\bf z}_{n})}\Big[\alpha_{n}\cdot\log p({\bf z}_{n}|\alpha_{n}=1)`$ |  |  |
|  |  | $`\displaystyle+(1-\alpha_{n})\cdot\log p({\bf z}_{n}|\alpha_{n}=0)\Big]\Big)`$ |  | (39) |

which is a Bernoulli distribution with the following parameter:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi_{n}=g\Big(\mathbb{E}_{r({\bf z}_{n})}\Big[\log\frac{p({\bf z}_{n}|\alpha_{n}=1)}{p({\bf z}_{n}|\alpha_{n}=0)}\Big]+\log\frac{\pi}{1-\pi}\Big),
``` |  | (40) |

with $`g(.)`$ being the sigmoid function.

#### B-A4 M-step

After updating all the variational distributions, the next step is to
update the set of parameters, i.e.
$`\Theta=\left\{\mathbf{W},\mathbf{H},\pi\right\}`$. To do so, we need
to optimize the complete-data log-likelihood which reads:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle Q(\Theta;\Theta^{old})`$ | $`\displaystyle=\mathbb{E}_{r({\bf s})\cdot r({\bf z})\cdot r({\mbox{\boldmath$\alpha$}})}\Big[\log p({\bf x},{\bf s},{\bf z},{\mbox{\boldmath$\alpha$}};{\mathbf{v}},\Theta)\Big]`$ |  |  |
|  |  | $`\displaystyle\stackrel{{\scriptstyle cte.}}{{=}}\sum_{f,n}-\frac{|x_{fn}-m_{fn}|^{2}+\nu_{fn}}{({\bf W}{\bf H})_{fn}}-\log({\bf W}{\bf H})_{fn}`$ |  |  |
|  |  | $`\displaystyle\qquad+\pi_{n}\log\pi+(1-\pi_{n})\log(1-\pi)`$ |  | (41) |

The update formulas for $`\mathbf{W}`$ and $`\mathbf{H}`$ can be
obtained by using standard multiplicative updates \[[41](#bib.bib41)\]:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{H}\leftarrow\mathbf{H}\odot\frac{\mathbf{W}^{\top}\left({\mathbf{V}}\odot\left(\mathbf{W}\mathbf{H}\right)^{\odot-2}\right)}{\mathbf{W}^{\top}\left(\mathbf{W}\mathbf{H}\right)^{\odot-1}},
``` |  | (42) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{W}\leftarrow\mathbf{W}\odot\frac{\left({\mathbf{V}}\odot\left(\mathbf{W}\mathbf{H}\right)^{\odot-2}\right)\mathbf{H}^{\top}}{\left(\mathbf{W}\mathbf{H}\right)^{\odot-1}\mathbf{H}^{\top}},
``` |  | (43) |

where $`{\mathbf{V}}=\Big[|x_{fn}-m_{fn}|^{2}+\nu_{fn}\Big]_{(f,n)}`$,
and $`\odot`$ denotes element-wise operation. Optimizing over $`\pi`$
leads to a similar update formula as in
([25](#S3.E25 "In III-C2 Optimizing w.r.t. 𝚯 ‣ III-C Training the MIN-VAE ‣ III The Mixture of Inference Networks VAE ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")):

|     |                                       |     |      |
|-----|---------------------------------------|-----|------|
|     |
       ``` math
       \pi=\frac{1}{N}\sum_{n=1}^{N}\pi_{n}.
       ```                                    |     | (44) |

### B-B Speech Estimation

Let $`\Theta^{*}=\left\{\mathbf{W}^{*},\mathbf{H}^{*},\pi^{*}\right\}`$
denote the optimal set of parameters found by the above VEM procedure.
An estimation of the clean speech is then obtained as the variational
posterior mean ($`\forall f,n`$):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\hat{s}_{fn}=\mathbb{E}_{r(s_{fn})}[s_{fn}]=\frac{\gamma_{fn}^{*}}{\gamma_{fn}^{*}+\left(\mathbf{W}^{*}\mathbf{H}^{*}\right)_{fn}}\cdot x_{fn},
``` |  | (45) |

where, $`\gamma_{fn}^{*}`$, defined in
([34](#A2.E34 "In B-A1 VE-𝑟(𝐬_𝑛) step ‣ B-A Parameters Estimation ‣ Appendix B Speech enhancement ‣ Mixture of Inference Networks for VAE-based Audio-visual Speech Enhancement")),
is computed using the optimal parameters.
````
